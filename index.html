02 / 기준색 HSV

S / V 곡선

● 생성 단계 · ◆ 입력 기준

− / +는 휘는 방향입니다. 현재 생성 범위에서 최대 120°까지만 휘도록 완만하게 조절합니다.

1× = 입력 B가 +1단계. 작게 하면 촘촘하게, 크게 하면 넓게 배치합니다. A와 Hue 변화량은 유지됩니다.

가로 S · 세로 V · 축 범위 0~100 고정
◆ B는 1× 간격의 입력 기준입니다. 간격 조절 후 실제 +1 위치는 주황 원으로 표시합니다.
선은 원본 곡선, 작은 원은 실제 생성 색입니다. 원본 곡선 위 간격은 동일하며, clamp 후에는 달라질 수 있습니다. 겹치는 점에 마우스를 올리면 단계 목록이 표시됩니다.
